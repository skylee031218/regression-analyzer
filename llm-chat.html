로컬 LLM 대화창

내 컴퓨터의 LM Studio에서 실행 중인 오픈소스 LLM(Qwen3 8B)과 대화합니다.

연결 확인 전
LM Studio에 연결되지 않았습니다. 아래 순서로 확인해 주세요.
  1. 이 컴퓨터에서 LM Studio를 실행합니다.
  2. LM Studio의 로컬 모델 API 화면에서 서버를 켜고, CORS 허용도 켭니다.
  3. 모델(Qwen3 8B)을 불러옵니다.
  4. LM Studio의 로컬 모델 API 화면에 적힌 포트(예: 1235)가 위 서버 주소와 같은지 확인합니다. (1234와 1235는 자동으로 찾습니다.)
  5. 이 화면의 [연결 확인]을 누릅니다. 브라우저가 "로컬 네트워크 접근" 허용을 물으면 허용을 선택합니다.
설정
모델은 내 컴퓨터에서만 실행되며, 입력한 내용은 외부 서버로 전송되지 않습니다.
