# 회귀 분석기 (데이터처리개론 과제)

데이터 파일을 열고 X축과 Y축을 고르면, **선형 회귀(직선)** 와 **비선형 회귀(곡선)** 결과를 그래프로 보여주는 웹 프로그램입니다.

👉 **실행하기 : https://아이디.github.io/저장소이름/** (GitHub Pages 주소로 바꾸기)

## 기능

- CSV, 엑셀(xlsx), 공백 구분 텍스트(.data) 파일 열기
- X축, Y축 직접 고르기
- 선형 회귀와 2~5차 비선형 회귀 비교 (회귀식, R², MSE)
- 예측 계산기 : X 값을 넣으면 Y 값 예측
- 경사하강법 오차 감소 그래프, 차수별 R² 비교 그래프
- 예제 데이터 : 배의 속도와 물의 저항 (UCI Yacht Hydrodynamics)

## 알고리즘

라이브러리를 쓰지 않고 `index.html` 안에 직접 구현했습니다.

- **최소제곱법** : 잔차 제곱합을 각 계수로 미분해 0이 되는 식 (XᵀX)θ = Xᵀy 를 가우스 소거법으로 풉니다.
- **경사하강법** : θ ← θ − 학습률 × 기울기 를 오차가 더 이상 줄지 않을 때까지 반복합니다.
- **표준화** : x, x², x³ 의 크기 차이 때문에 경사하강법이 폭주하지 않도록 각 열을 평균 0, 표준편차 1 로 맞춥니다.
- 두 방법으로 구한 결과가 같은지 화면에서 확인할 수 있습니다.
