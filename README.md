# 회귀 분석기 (데이터처리개론 과제)

데이터 파일을 열고 X축과 Y축을 고르면, **선형 회귀(직선)** 와 **비선형 회귀(곡선)** 결과를 그래프로 보여주는 웹 프로그램입니다. 두 번째 과제로 **인공신경망** 탭을 추가하여, 같은 데이터를 신경망으로 학습하고 회귀 결과와 비교할 수 있습니다.

👉 **실행하기** : https://skylee031218.github.io/regression-analyzer/

📝 **설명서 (Notion)** : https://app.notion.com/p/3f33fa11c4f180f28d3ece8be64374e6?source=copy_link

## 기능

### 회귀 분석 탭

- CSV, 엑셀(xlsx), 공백 구분 텍스트(.data) 파일 열기
- X축, Y축 직접 고르기
- 선형 회귀와 2~5차 비선형 회귀 비교 (회귀식, R², MSE)
- 예측 계산기 : X 값을 넣으면 Y 값 예측
- 경사하강법 오차 감소 그래프, 차수별 R² 비교 그래프
- 예제 데이터 : 배의 속도와 물의 저항 (UCI Yacht Hydrodynamics)

### 인공신경망 탭

- 신경망 구조 그림, 학습 곡선, 예측 vs 실제 그래프, 모델 비교 표, 예측 계산기
- 신경망 모양 선택 : 은닉층 1층, 2층, 3층 / 층마다 노드 4개, 8개, 16개, 32개 / 활성화 함수(ReLU, tanh, 시그모이드)
- 학습 설정 선택 : 학습 횟수, 학습 속도
- 시험 데이터 선택 : 무작위 20% 또는 **선체 단위**(학습에 나오지 않은 선체로 평가)
- 직선, 3차 곡선, 선형 회귀(입력 전부)와 **같은 시험 데이터**로 성능 비교
- 회귀 탭에서 연 데이터를 자동으로 가져오며, 다른 CSV·엑셀 파일도 사용 가능

## 알고리즘

라이브러리를 쓰지 않고 직접 구현했습니다. 회귀는 `index.html`, 인공신경망은 `nn.js` 에 있습니다.

### 회귀 (`index.html`)

- **최소제곱법** : 잔차 제곱합을 각 계수로 미분해 0이 되는 식 (XᵀX)θ = Xᵀy 를 가우스 소거법으로 풉니다.
- **경사하강법** : θ ← θ − 학습률 × 기울기 를 오차가 더 이상 줄지 않을 때까지 반복합니다.
- **표준화** : x, x², x³ 의 크기 차이 때문에 경사하강법이 폭주하지 않도록 각 열을 평균 0, 표준편차 1 로 맞춥니다.
- 두 방법으로 구한 결과가 같은지 화면에서 확인할 수 있습니다.

### 인공신경망 (`nn.js`)

- **구조** : 입력층 → 은닉층(1~3층) → 출력층. 출력층은 활성화 함수 없이 값을 그대로 출력합니다 (회귀 문제).
- **순전파** : 각 노드에서 `z = Σ(w·x) + b` 를 계산한 뒤 활성화 함수 `a = f(z)` 를 적용하여 비선형을 만듭니다.
- **손실 함수** : MSE = (1/n)·Σ(y − ŷ)²
- **역전파** : 합성함수 미분법(체인 룰)으로 출력층에서 입력층 방향으로 기울기를 계산합니다.
- **최적화** : Adam (경사하강법을 개선하여 가중치마다 걸음 크기를 자동으로 조절)
- **학습 방식** : 미니배치 32개, 입력과 출력 표준화(학습 데이터의 평균·표준편차만 사용), 난수 시드 42로 고정하여 같은 설정에서는 같은 결과가 재현됩니다.
- **검증** : 역전파로 구한 기울기를 수치 미분과 비교하여 일치함을 확인했습니다 (ReLU, tanh, 시그모이드).

## 실행 결과 (예제 데이터)

예제 데이터 308행(22개 선체 × 14개 속도), 신경망은 은닉층 2층 × 16노드, ReLU, 1000번, 학습 속도 0.01 입니다.

| 시험 데이터 | 모델 | 시험 R² | 시험 RMSE |
|---|---|---|---|
| 무작위 20% | 직선 (속도만) | 0.667 | 7.968 |
| 무작위 20% | 3차 곡선 (속도만) | 0.986 | 1.609 |
| 무작위 20% | 선형 회귀 (입력 6개) | 0.639 | 8.286 |
| 무작위 20% | **인공신경망** | **0.989** | **1.44** |
| 선체 단위 | 직선 (속도만) | 0.661 | 8.481 |
| 선체 단위 | 3차 곡선 (속도만) | 0.984 | 1.821 |
| 선체 단위 | 선형 회귀 (입력 6개) | 0.662 | 8.478 |
| 선체 단위 | **인공신경망** | **0.962** | **2.845** |

- 직선과 선형 회귀는 저항이 속도에 따라 급격히 커지는 비선형 관계를 표현하지 못합니다.
- 시험 데이터를 무작위로 고르면 신경망이 가장 좋았지만, **처음 보는 선체**로 평가하면 속도 하나만 쓴 3차 곡선이 더 정확했습니다. 선체가 22개뿐이어서 신경망이 선체 모양 값을 외운 것으로 보입니다.
- 평가 방법에 따라 결론이 달라질 수 있습니다. 자세한 해석은 Notion 설명서에 정리했습니다.
